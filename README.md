# Soulbound Abilities

Soulbound Abilities is a Minecraft plugin that introduces a stamina system and unique abilities for players. Players start with 5 stamina points and gain one stamina point for each player they kill. Unlocking abilities requires reaching specific stamina or kill milestones. The plugin includes four abilities: Feel the Power, Supersonic, Hyper Generate, and Ultimate Power.

## Install

1. Download the plugin JAR file from the [GitHub releases page](https://github.com/EnderDevelopment/SoulboundAbilities/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server.

## Use

1. Players start with 5 stamina points.
2. Gain 1 stamina point for each player killed.
3. Unlock abilities by reaching specific milestones:
   - **Feel the Power**: 15 stamina points.
   - **Supersonic**: 50 kills.
   - **Hyper Generate**: 30 stamina points.
   - **Ultimate Power**: 100 kills.
4. Use the `/stamina` command to check your current stamina.
5. Use the `/abilities` command to list your unlocked abilities.
6. Use specific items to activate abilities:
   - **Feel the Power**: Bone.
   - **Supersonic**: Feather.
   - **Hyper Generate**: Blaze Rod.
   - **Ultimate Power**: Nether Star.
